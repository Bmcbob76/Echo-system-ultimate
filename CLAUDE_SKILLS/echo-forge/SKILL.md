# 🔥 ECHO FORGE - Swarm Intelligence Program Generation

## Description
ECHO Forge is an advanced program generation system using swarm intelligence to create complete software applications. It orchestrates 1200+ AI agents across 50+ specialized guilds to collaboratively build anything from games to operating systems through natural language instructions.

## When to Use This Skill
Use ECHO Forge when you need to:
- Generate complete programs from conversational descriptions
- Create full-stack applications (web, desktop, mobile)
- Build games or game engines from scratch
- Design and implement operating systems
- Generate complex multi-file codebases
- Create frameworks, libraries, or SDKs
- Build systems that require multiple specialist perspectives

## Best Practices

### 1. Clear Specifications
❌ **Don't:** "Make a game"  
✅ **Do:** "Create a roguelike dungeon crawler with procedural generation, permadeath, turn-based combat, and ASCII graphics"

### 2. Leverage Guild Expertise
Explicitly request guild involvement:
- "Frontend Guild: Design the UI"
- "Security Guild: Implement OAuth2"

1. "Create basic MVP with core features"

3. "Implement AI opponents"
4. "Add monetization system"

### 4. Performance Optimization
Request competitive scoring focus:
- "Optimize for speed - Backend Guild competes on response time"
- "Minimize memory usage - agents compete on efficiency"
- "Maximize battery life - Mobile Guild optimization battle"

### 5. Quality Assurance
- Always request Testing Guild validation
- Use Security Guild for security audits
- Request DevOps Guild for deployment pipelines
